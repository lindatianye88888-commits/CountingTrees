# 0.3.27 项目植物采集

“项目植物与规格 → 更新已有植物”从图中补充项目规格，允许混选乔木、灌木球图块、区域、区域引线以及普通名称文字。空项目也可使用。原“按当前定义批量更新”仍在编辑菜单，用于将当前定义应用到已有同规格图块。

带数树数据的图块或区域沿用其规格；选择它们的关联文字、引线或填充时定位到原对象，同一来源只处理一次。普通名称文字与项目唯一规格匹配时直接收录；同名多个规格时显示候选表，供设计师选择；新名称打开规格窗口确认。未提供的尺寸留空，同批相同品种、规格只确认一次。

按设计师要求，普通文字只提供名称，其显示的株数、面积不计入数量。普通单株图块按实例计数，第二行胸径数字不当作株数。包含多种植物或读取被截断的大图块跳过。用户取消或源图层锁定时不写入该对象。

名称文字登记后，“图中调用”能读取其对应项目植物。直接改名称文字后再次采集，可重新确认品种。项目定义修改后，登记对象在数量表中使用最新项目参数；采集不改画普通图块的几何或其共享块定义。

采集结束立即刷新数树关联表，保留表格实体及原统计范围、类别和品种过滤。仅名称而无数量的品种在数量表显示“待关联”，其数量不当作零。后续关联到同一项目规格的图块或区域后不再重复显示待关联行。关联表图层锁定时先停止并提示解锁；手工静态表不自动纳入数树关联。

## 验证范围

- 296 项自动检查通过，包括混选去重、重复采集、普通文字不计量、新品种取消、锁定对象、同名规格选择、分类和框选表范围、只有名称时生成总表，以及后续关联面积后的去重。文字解析器另在 .NET Framework 实际执行了 19 组用例，包含在上述自动检查中。
- 六组 DLL 均按对应 AutoCAD SDK 编译通过。2015—2024 和对应天正的实际宿主验收仍未完成。
- 实际 WinForms 项目窗口通过 16 项交互检查，包括空项目采集入口、缩放、过滤、排序后的规格索引，以及同名规格选择；已渲染核对。
- `developer/verify_project_import.py` 提供独立图纸副本中的原生采集、关联表即时更新和保存重开检查。本轮 AutoCAD 2014 Core Console 在执行脚本前退出，未生成断言结果，这一组没有计为通过。尚需真实 CAD 中验证选取、实体 LDATA、表格写入及保存重开。

开发检查不连接、不保存用户当前图纸。内核测试只使用安装目录示例的独立副本，窗口测试不连接 CAD。

## CAD 中复核

在图纸副本中打开项目植物，点“更新已有植物”，同时选择一株乔木及其关联文字、一处灌木区域及其引线、一个普通名称文字，回车确认。检查项目规格增加，已有总表刷新且同一来源未多算。再次采集应保持数量不变；仅名称的条目应显示待关联。对同名不同尺寸的规格，确认弹出候选表，并能取消退出。保存测试副本重开，复核关联及表格。
