# 0.3.28 灌木标注字高修复

旧实现同时受两个限制：已有区域按创建时记录的单位换算文字高度；两点引线又会将文字缩进既定横线。放大纸面字高后，缩字逻辑抵消了设置。区内面积指标也存在按区域半径限制字高的逻辑。

现在统一按当前设置计算文字高度：`纸面字高(mm) × 出图比例 × 每米图纸单位 / 1000`。设置窗口仍输入 cm，先换算为 mm。布局纸空间不乘模型出图比例。未配置当前单位的旧图，暂沿用对象原有单位作为文字换算的回退。

新旧乔木文字、灌木引线和区内面积指标使用同一计算入口。短横线自动延长，文字不再按线长缩小；折点、左右方向及单行/双行布局保留。图纸内专用文字样式保持可变字高，避免固定字体高度覆盖设置。已有引线样式标记升级为3，首次同步即修正曾被压小的字。

设置保存后统一刷新一次，避免先刷新乔木、随后又全图刷新。单位校准变化也触发文字刷新。实体本身记录的计量单位保留，面积和冠幅不因改文字设置而重算。旧设置没有编号开关字段时，按关闭显示初始化，避免窗口读取空整数失败。

## 验证

- 309项自动检查：覆盖单位/比例/字高、新旧引线、区内指标、纸空间、设置保存和取消、单次刷新、旧样式升级，以及已有项目采集、统计和协议回归。新增的12组尺寸案例执行实际C#横线计算方法，使用CAD对象替身，属于独立方法测试。
- 六组AutoCAD SDK编译通过。
- AutoCAD 2014独立配置、示例副本通过209项检查：185项实际原生MLeader、填充及关联表回归，19项设置到实际MLeader/MTEXT及面积不变的检查，5项保存重开检查。包含左右方向、单/双行、短横线放大字高、移动后刷新和箭头随字高调整。
- 设置窗口回调及每实体LDATA采用确定性适配；实际MLeader/MTEXT写入、图纸保存和重开使用真实CAD数据库。这不等同于用户图纸的桌面鼠标验收，2015—2024也仍待对应宿主验收。

开发验证只操作独立示例副本，未连接、修改或保存用户当前图纸。独立配置参数按[Autodesk的Core Console说明](https://blog.autodesk.io/getting-started-with-accoreconsole/)使用，避免测试参数影响日常CAD。

## 使用

安装0.3.28并重开CAD，在已有图纸执行一次`PLANTCADSYNC`。之后从“设置 → 图纸单位、比例与字高”调整，保存设置即可同时刷新灌木标注。纸面字高例如0.25cm即2.5mm。
