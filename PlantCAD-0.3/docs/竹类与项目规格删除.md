# 0.3.30 竹类、默认字高与规格删除

项目植物窗口新增独立的“竹类”分类。品种库原有青皮竹、麻竹、青杆竹，新增刚竹、淡竹、慈孝竹、箬竹、方竹、罗汉竹、紫竹、黄皮刚竹、斑竹、金镶玉竹、凤尾竹、阔叶箬竹、菲白竹、锦竹，共17项。新增名单参考[上海市绿化和市容管理局园林竹类文章](https://lhsr.sh.gov.cn/jnylwh/20221019/2f8b7da5b4884f2eb63423af0c707d2f.html)，适生范围、苗木规格与供苗需由设计师确认。

从品种库选择“竹类”建立规格，默认计数单位为丛，允许改为株。竹类使用独立图例和标注图层，分类数量表中与乔木同组。已有项目的自定义品种库会补入缺失的竹类，不覆盖同ID或同名的自定义条目；历史规格的类别不自动改写，可在“修改规格”中选竹类。新竹类规格没有预设尺寸，布置前填写实际冠幅。

“设置 → 单位／比例／字高”中，未配置图纸的纸面字高默认为 **1 cm**，内部保存为10 mm，按出图比例换算模型字高。已有图纸保存过的字高继续沿用，可手动改成1；填充比例未改动。

在“项目植物”中选择一行，点击“删除规格”。确认框列出图上对象数量和将删除的独立表数量，默认选择不删除。确认后删除该规格对应的植物图块、采集的植物文字、计算区域、标注、引线、填充及辅助填充轮廓；混合表移除对应记录，仅含该规格的表删除。取消不改动任何内容；关联图层锁定时先提示解锁。

删除按项目规格ID处理，同名但不同编号的规格独立保留。原始底图边线、共享图块定义和品种库不删除。删除后返回CAD，可用U撤销本次命令的改动。原生对象删除在一个事务中完成；后续项目元数据与表格刷新处于命令撤销组内，异常时查看命令提示并撤销，不承诺跨模块的单事务原子性。

验证范围：313项规则自动检查、10项MCP协议检查、19项实际WinForms窗口检查、53项AutoCAD 2014 CoreConsole删除／撤销／保存重开检查、209项字高及引线回归。删除测试使用独立配置与测试图副本；确认按钮和实体LDATA使用测试适配，真实图形、HATCH、原生表格、事务与DWG读写均由CAD执行。尚未完成天正桌面鼠标及打印验收；2015—2024为SDK编译通过，配套实机验收待完成。
