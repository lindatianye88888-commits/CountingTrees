## 安装和调用

先保存并关闭CAD，运行安装操作面板.cmd。安装器复制8个共享运行文件和6个自有插件DLL；安装器需要Python3。AutoCAD通过PackageContents.xml的6组SeriesMin/SeriesMax选择对应DLL，用户无需手工挑选，也不会将2014 DLL声明成全部版本通用。保留原bundle位置、产品标识、DWG字典、图层、块名和旧命令，避免重复加载或丢失旧图关联。

安装后输入COUNTINGTREES或数树打开。建议通过完整安装包调用；若临时NETLOAD，须选择自己CAD对应组目录里的DLL，不能跨组手动加载。2014仍使用bridge/PlantCADBridge.dll，其余位于bridge/版本组/PlantCADBridge.dll。

此包不包含AutoCAD、天正或Autodesk SDK，不支持32位CAD、Mac、AutoCAD LT、浩辰及中望；2025及以上不在本轮目标内。Windows系统版本也应满足对应AutoCAD和天正的官方要求，不能仅凭插件可编译推断旧CAD支持新系统。

## 已检查的内容

6组均使用真实Autodesk SDK引用编译，并读取最终程序集引用，核实实际依赖19.1、20.0、21.0、22.0、23.0、24.0；不是只改版本号。新增路由检查覆盖2014—2024每个版本唯一匹配、上下界排除、64位限制、旧命令、14个配套文件和既有产品身份。

在本机AutoCAD2014内核中，分别从平铺路径和版本组子目录加载实际插件，核对共享LISP/植物库根目录、MCP队列配置及三个入口。读取和写入仅发生在测试副本。

高版本SDK引用来自Autodesk账号发布的[AutoCAD.NET](https://www.nuget.org/packages/AutoCAD.NET/24.0.0)系列NuGet包。引用仅用于编译，缓存位于developer/bin/sdk-cache，不分发到插件包。包来源和散列保存在缓存references.json中。

## 尚需验收

每个目标CAD/天正组合需实际验证：启动加载、中文与DCL/WinForms窗口、单株/灌木球、混合边线和补面积、两点引线、移动及撤销、灰色填充、规格修改与表格回写、统计拆分、保存重开及打印。2021—2024还需覆盖实际LISPSYS设置；本插件不擅自修改该变量、CAD安全策略或天正菜单。

当前不能在宣传中写“2014—2024所有功能全面实测通过”。准确状态是“已提供2014—2024分版适配开发包，高版本待配套实机验收”。
