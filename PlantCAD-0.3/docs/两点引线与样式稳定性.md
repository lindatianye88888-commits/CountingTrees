# 0.3.22：两点引线及标注样式稳定性

## 操作

在“开始布置 → 已算面积引线标注”，或执行 `PLANTCADLABELAREA`。

1. 选中已计算的区域、面积文字或填充，确认单行/双行样式。
2. 第一点指定引线折点，第二点指定横线尾端；向左/向右决定方向，尾端自动投影到折点水平线上。
3. 最后在窗口检索、选择项目植物的具体规格，或输入植物名称/规格编号。可从品种库添加；同名多规格必须明确规格。
4. 确认后生成整体引线；有填充选项时再更新该区域填充。点位回车或取消品种窗口保留该块原有内容。

0.3.28起横线长度不足时自动延长，文字保持设置的出图字高；较长横线保留当前长度。原生MLeader包含文字和引线，MOVE、夹点移动及撤销保持整体。

## 样式处理

原实现刷新时会重新使用CAD当前文字样式，且只给出一个文字点，原生引线会根据文字宽度和方向重算折点。新实现保留原字体，左右两侧明确指定同一文字附着规则；图纸中新建专用文字/引线样式，后续切换TEXTSTYLE或CMLEADERSTYLE不改变新标注的模板。

每条标注保存自己的单行/双行配置。修改后续标注默认样式不改变已有标注；换品种、刷新统计或比例时读取各自的配置。刷新前读取实际原生夹点位置，保留折点和左右方向；当前横线能容纳文字时保留尾端，文字变长时延长，不拿初次存储的点覆盖移动结果。

旧标注执行一次 `PLANTCADSYNC` 更新左右附着规则及版本标记；后续无内容/比例变化时不重复重写。普通CAD命令结束不自动整图计算。
