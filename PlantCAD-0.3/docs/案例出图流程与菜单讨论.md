# 案例出图流程与菜单讨论

本稿依据“案例”中的植物布置、植物总图、种植说明、图框及《20170118植物配置表.xlsx》，只用于讨论下一步菜单和数据设计。本轮没有重排菜单，也没有改动原案例。图纸副本提取结果保存在bridge/host-output/case-review-4cf0f270。

## 案例中的实际做法

- 模型按0-Tree、0-株状灌木、0-灌木、0-灌木标注、0-草坪等分层；布局有多个视口、图框及选型图片。植物主模型有167条LEADER和167段MTEXT，标注经常是“名称＋面积”，绿篱还有“名称＋长度”。
- 配置表分乔木和灌木两个工作表。灌木表又分单株灌木、片植灌木和水生植物；单株中既有九重葛球、海桐球，也有千层金、紫荆。入口不能把所有单株灌木都当作球形苗木。
- 同一品种有A/B/C等规格档；表内冠幅、米径、高度多用范围值，另有分枝点、密度与苗木质量备注。不能把“400–500cm”静默改成单个尺寸。
- 数量同时采用株、m²和m。灌木表第26行绿篱按米；第49/50行为花境和草坪，按面积。水生植物第52–54行写“株”但数量含小数，密度备注也混有“株/米”和“株/平米”，需要设计师确认，不能直接自动换算。

## 建议的绘图顺序

确认单位、比例、底图与图层 → 建立本项目植物规格 → 布置乔木/单株灌木 → 识别片植范围及绿篱长度 → 关联名称、填充与出图标注 → 分项统计 → 在布局核对出图。

先用项目规格确定同一品种的各规格档，点放和面积关联都引用同一规格。采购范围值与图形预览冠幅分开保存；预览冠幅由设计师指定。正式统计仍保留范围、分枝点、密度和质量备注。

## 菜单讨论建议

| 工作入口 | 常用动作 | 对应案例需求 |
| --- | --- | --- |
| 项目植物 | 植物库、本项目规格、同种规格档、图例 | 品种与项目规格分开；球形和普通单株灌木都可选 |
| 单株布置 | 乔木、单株灌木/灌木球、沿线、复制 | 按株统计，图形与编号关联 |
| 片植与绿篱 | 扫面积、量长度、指定植物、填充 | 片植m²与绿篱m分开；灌木默认灰色 |
| 标注与编辑 | 单株数量、名称面积/长度、整体引线、批量改规格 | 移动文字与引线同行；两种排版保留 |
| 统计与出图 | 乔木表、灌木表、分项数量、图例编号、布局检查 | 单株、片植、绿篱、水生和草坪计量清楚 |
| 项目设置 | 单位、比例、图层、字高、计量与表格字段 | 集中项目标准，避免每次操作重复选择 |

菜单优先呈现上面这条工作顺序。“开始布置”只放当前植物可执行的方式；低频设置放到项目设置，不在主面板重复占位置。

长度统计、范围规格、分枝点/密度字段和出图检查属于后续设计，尚未在本轮实现。建议先确认计量方式和规格字段，再定菜单名称与位置。
