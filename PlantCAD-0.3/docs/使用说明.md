# CountingTrees（数树） 第三版 · 植物布置、区域填充与关联出图

当前修订0.3.24，提供Windows AutoCAD2014—2024 64位的分版适配开发包。2014为本机CAD/TArch9环境；2015—2024及对应天正已完成分组编译，仍待配套实机验收。主界面为自动小圆标和可拖动浮窗。

## 0.3.24多版本适配

安装包按2014、2015—2016、2017、2018、2019—2020、2021—2024分为6组DLL，由CAD按版本加载。每组使用对应Autodesk SDK编译，保留旧图关联和命令；不需要用户手工更换DLL。对应天正需支持其使用的AutoCAD版本。

268项自动检查及本机2014内核回归单独记录；高版本“编译通过”不等于其鼠标交互、中文显示和打印已通过。详见[兼容性与测试矩阵](兼容性与测试矩阵.md)。

## 0.3.23软件名称

软件英文名为 **CountingTrees**，中文名为 **数树**。工作台、植物规格与品种窗口、小圆标提示、命令消息、安装信息和本地AI服务显示使用新名称。CAD中输入 `COUNTINGTREES` 或 `数树` 打开工作台。

已有命令和图纸关联继续兼容；原技术目录、数据字典及图层标识保留，避免旧图丢失关联。安装包为 `CountingTrees_数树_0.3_浮窗开发版.zip`。

## 0.3.22两点引线与样式稳定

“已算面积引线标注”（PLANTCADLABELAREA）改为：选择区域及样式 → 第一点指定引线折点 → 第二点指定横线尾端和左右方向 → 选择或输入植物品种。第二点自动与折点保持水平，回车或取消跳过当前区域。品种窗口支持项目规格检索、列表选定具体规格、从品种库添加和手输新名称；同名不同规格须明确选定。

原生整体引线保留每条标注的单行/双行布局。刷新保留字体、设计师移动后的几何位置及方向；新标注采用图纸内专用的文字和引线样式，切换CAD当前样式不再改变后续标注。旧标注执行一次PLANTCADSYNC应用更新。文字采用当前出图字高；点选横线不足以容纳整行时等比缩小文字，保持所选横线端点。

本轮260项自动检查、190项原生关联输出及两点标注流程与保存重开检查通过；真实鼠标/DCL交互和打印仍待桌面验收。详见[两点引线与样式稳定性](两点引线与样式稳定性.md)。

## 0.3.21整体复查修复

本轮检查几何计算、植物及规格、标注、填充、统计表、窗口、安装和本地连接协议。修复选择顺序影响面积、圆弧接缝面域失败、复合面域填充，以及重复扫描和旧区升级时的复用问题。

案例2的原117个已核对区域全部保留；四种选择顺序的轮廓和面积一致。当前输出118个几何闭合图形，额外一个为极小边角，仍需设计师确认用途；包含停车格等非种植图形，不自动当作植物种植区。

无法直接建立面域的少量圆弧接缝，在面积误差上限内做局部拟合，保留主要圆弧和原始边线。“编辑 → 查看植物或范围属性”可点区域边界或面积标注，查看面积、植物、补线及拟合状态。

249项自动检查、150项原生几何及关联出图等内核回归通过。安装版的鼠标交互、删除撤销和最终打印仍需桌面验收；当前测试CAD停在启动提示，该部分未计为通过。详见[整体复查报告](整体复查报告.md)。

## 闭合区域漏算修复

0.3.20继续处理案例2漏识别：寻环时认为已闭合的微小接缝，可能仍被CAD面域内核拒绝。新增在原数值容差内统一临时计算轮廓端点，保留直线和圆弧段，并校验拟合面积误差。原始边线不平移、不重画；较大缺口仍沿用独立补线和“约数”标记。

几何识别结果包括所选图层上的全部闭合图形；停车位、道路等轮廓不会自动判定为种植区。确认植物种类后再关联种植面积。

## 项目窗口调整大小与面积识别修复

“项目植物与规格”窗口可以拖动边框或四角调整大小，也可以最大化。植物列表随窗口扩展，八列参数保持对齐，列宽也可拖动调整；本次CAD会话记住上次窗口大小。分类、名称/编号检索、双击修改规格以及原有按钮继续保留。植物参数仍通过“修改规格”保存并同步关联对象。

修复大坐标边界交点切分引发“计算边线围合面积：eInvalidInput”的问题。几何在临时局部坐标中计算，输出面域和标注还原到原图位置；原边线的平面形状不变。安装更新后可重新执行灌木边线自动识别，带约数的推定补线区域仍需核对。

## 灌木球、花境和草坪

“选植物 → 植物库”的“形态”下拉菜单可直接选择灌木球、花境、草坪。选灌木球时展示可供设计师选择的灌木品种，右侧已选项标记“灌木球”，建立规格时自动使用灌木球类别和初始冠幅；同一品种也可以作为普通灌木选择。实际球形苗木供应、规格和适生条件仍由设计师确认。

“植物规格与图例”窗口新增全部植物下拉选择，可选择植物库中的植物；名称也可手动修改。类别包括乔木/竹类、灌木/藤本、花草/地被、灌木球、花境、草坪。植物规格使用cm。

点击绿色“开始布置 ▾”后才展开布置方式。选择“灌木球（单株）”时，使用与乔木相同的插入、冠幅和图例文字方式，图形分别进入PL_灌木球_圆圈、PL_灌木球_简化，名称和引线进入PL_灌木球_标注。由普通植物改用灌木球入口时建立独立规格，已有乔木规格不变。

## 已算面积自动填充和出图引线

1. 先扫描面积。选择对应的计算面域、面积文字或已有填充。
2. 设置当前植物，再从“开始布置”或“布置”菜单选择“已算面积自动填充”。可多选，回车确认；按当前植物关联并生成CAD原生HATCH。
3. 图案默认按植物种类稳定分配，允许不同植物使用相同图案。在项目规格中可明确选择ANSI31至ANSI38，设置比例及角度。灌木、草地/地被、花境使用独立填充图层。
4. 填充保留扫描面域的曲线和内孔，同一区域再次填充会替换旧填充，不叠加。锁定图层会提示处理。计算面域仍是扫描时的快照；原始灌木线变更后需重新扫描。
5. 出图标注使用“已算面积引线标注”，或“标注 → 区域编号或植物名称与面积”。先选择面积，再选择样式：上行植物、下行面积；或植物在前、面积在后，同排放在线上方。
6. 新生成的出图引线为CAD原生MULTILEADER，文字、横线和箭头属于一个对象；MOVE、夹点移动和撤销时一起调整。已有分离标注执行一次“更新关联标注”（PLANTCADSYNC）转换，锁定层跳过。
7. 第一处点击确定折点，第二处点击确定横线尾端及左右方向；横线自动保持水平。随后在品种窗口选择项目规格，或输入植物名称/规格编号。唯一项目规格直接复用；同名多规格须从列表选定或输入编号，新名称建立无虚构尺寸的面积规格。
8. 灌木填充默认灰色（ACI8、随图层）。旧版默认黄/绿灌木填充层在首次初始化或重新填充时转换；其他自定义颜色不强制改变。
9. 可同时填充，多块区域可默认沿用上一次选定的品种，并逐块更改。取消点选或品种窗口时保留该块原有绑定、标注和填充。文字按当前出图比例和纸面字高生成，过短横线内等比缩小，保留约数及补线推定说明。先生成引线和文字，再执行填充；个别区域填充失败时保留标注并在命令行提示。

0.3.14优化旧统计表刷新：批量改动时暂缓表格重建，只写变化单元格，异常时恢复原重建设置。避免标注结束时逐格重画全表。

0.3.12减少了无效刷新：仅打开窗口、切换当前植物不重画全图；修改项目规格时仍同步全部同规格对象。边界缓存会在几何修改时失效，实际修改后会重新计算；手动“更新关联标注”仍可强制同步。

## 带图例、编号的关联表和规格修改

“统计全部模型空间”“统计所选范围”完成统计后直接指定CAD表格插入点。数量/面积表、植物名录表、植物规格表均为带规格编号和实际图例的原生ACAD_TABLE；数量表保留全图或所选对象范围。

各表列顺序为：编号、图例、植物名称、类别、胸径、地径、高度、冠幅、数量/面积、单位。0.3.16修复清空单元格内容后，数据行字高退回字体固定值、导致只剩小点的问题。已有带关联的表执行一次“标注 → 更新关联标注”（PLANTCADSYNC），在原位置更新列顺序与文字显示。

统计菜单新增三个入口：

- “分类数量表（乔木/灌木球/灌木地被）”：选择统计范围，点第一张表的左上角，自动向下排三类表；没有数据的类别跳过。花境、草坪和普通灌木归入灌木地被表。
- “按品种生成数量表”：同一品种的不同规格保留为多行，归在同一张表内；各品种分别成表，自动向下排列。
- “拆分已有表格（按类别/品种）”：点选已有CountingTrees（数树）数量表、名录表或规格表，选Category三类或Species品种，再点新表位置。沿用原表统计范围，原表保留，可自行移动新表或删除总表。普通无关联表需要先重新统计。

分表保存类别或品种筛选，后续规格、名称和统计量修改仍按各表范围刷新；不会在同步时重新变成总表。一次拆分复用统计结果，避免逐表重复扫描图纸。

手输灌木名称生成的面积规格保留“平方米”单位，项目规格中可继续编辑；这类规格用于面积填充和标注，单株布置请改用株或丛。

在“修改当前植物规格”或“项目规格 → 修改规格”中保存修改，会保留该规格ID，同步当前图中同规格的植物、范围关联、图例、标注、填充及受管理表格。图中双击单株仍只修改所选单株，尺寸不同时使用独立规格。

也可直接编辑新关联表的植物名称、规格编号、胸径、地径、高度和冠幅。尺寸以cm输入，编辑后执行“标注 → 更新关联标注”（PLANTCADSYNC）同步。数量、面积、类别、单位、图例按项目和图纸数据生成；手动改动计算列会在同步时恢复。类别或填充图案请从项目规格修改。

为处理删除后卡死，0.3.13取消普通CAD命令结束后的自动全图写入。普通CAD移动、删除或直接编辑表格后，按需执行“标注 → 更新关联标注”（PLANTCADSYNC）；项目规格保存仍在同一次操作中自动更新全部关联对象。手动同步会补回仍有关联区域的缺失填充；需要删除整个区域时请删除对应计算面域。发现不合法的规格或锁定图层会提示修正。每次打开图纸先双击小圆标展开工作台，加载当前图纸的绘图和关联模块。Ctrl+S保存所有关联数据。

仅CountingTrees（数树）生成或管理的标注、填充和表格参加关联；普通手工文字与其他软件表格不会自动变成关联对象。旧版本表格保留原刷新方式，重新生成后具有图例和表格规格回写能力。

## 自动计算和标注

1. 双击植物小圆标展开浮窗。
2. 点击“布置 → 灌木线自动识别面积并标注”（完整命令PLANTCADAREA）。无需先选植物、填写尺寸或手动闭合。
3. 框选要处理的灌木边线，包括外围线、内部隔线，**按回车开始计算**。命令行显示“找到xx个”时还在选择阶段，可继续框选；Esc为取消。已有预选曲线会直接采用，可以同时选到底图其他对象。
4. 唯一黄色曲线图层自动采用；框选中只有一个有效曲线图层时也自动采用。多个候选无法确定时，点一条灌木线确认图层。
5. 软件将框选中所确认灌木图层的边线标高归零、颜色统一为随图层，再识别真实交点、恢复可推定断口、计算全部有效围合区域。底图单位只负责换算平方米；未知时按提示确认，比例不明可先退出去设置中按已知长度校准。
6. 自动在每块区域内部放置区域编号和面积，不再逐块点击。未关联植物也可统计。再次扫描相同区域会复查内部面积文字，缺失时补回；保留已有编号、植物关联和单位，不重复生成计算面域。已有内部文字会更新并放回区域内部，出图引线保留。

自动识别支持LINE、PLINE、SPLINE、圆弧、圆及椭圆的平面混合边界。包括真实交叉、共用边、未接上的端点、端点未碰到边界、未闭合的多段线/简单线串、两侧平行线组成的开口长条、重复线和多余尾线。内孔按几何嵌套关系处理，相邻区域保持分别计算。

归零和颜色统一只作用于框选范围内、已确认灌木边界图层的有效原始曲线，保留对象句柄、图层和附加资料。X/Y平面轮廓保持；直线端点、多段线/旧式二维及三维多段线、样条和水平圆弧等支持归零。倾斜圆弧等需要改变实体类型时提示处理，本次事务回滚；锁定图层需先解锁。颜色设置为随图层：新建灌木层默认黄色，已有自定义图层沿用其图层色，设计师以后改图层颜色即可统一调整。

归零后，缺口推定仅在副本进行，不JOIN、拉伸或关闭原线。未选边线及其他图层保持原样；不会修改用户的图层显示、冻结或锁定状态。

无需补线的区域按CAD曲线面域计算。需要恢复缺失边界时，标注为“约xx平方米（补线推定）”；红色PL_面积_推定补线图层显示推定连接，便于核对。仅用了补线的区域及受影响内孔标为约数，不把推定形状当作已知原始边界。

连接距离会随图形尺寸和局部线长调整，结合线头方向、同一线串和窄带关系判定。严重缺边或多种同样合理的接法无法唯一决定真实设计面积；软件保留原线并报告剩余开放线头或无效轮廓，不给无法确定的区域编造精确面积。剩余开放线头也可能只是多余尾线，已闭合区域仍会计算。

本次修复同一条直线多个交点的拆分顺序，避免反向边界漏算或重叠面积。计算开始、闭合数量和标注完成会在命令行显示。失败时保留原始原因及失败阶段，按Esc正常结束；树木图层关闭仅影响放树，不妨碍几何面积识别。

计算范围是独立面域快照。原线后续更改时，删除相应旧计算范围、旧标注及不再需要的推定补线，再重新识别。编辑受管理面域后可用“标注 → 更新关联标注”刷新文字。

## 手动补面积

“布置 → 手动补面积（点闭合线/框选）”，命令PLANTCADAREAADD。无需先选植物，按当前确认的底图单位换算平方米。

- 默认Boundary：点一条闭合多段线、圆、椭圆、闭合样条或面域，立即在内部生成编号和面积。可以连续点选，回车结束。已有计算区域的文字缺失时补回，编号和植物关联保留。
- Edges：框选组成围合的全部散线，可以跨图层、跨颜色；对选择范围内实际闭合的有效区域批量生成指标。适合自动扫描确认的单一灌木图层未包含全部边线的情况。

手动测量在曲线副本上计算，保留原边线的标高、颜色和图层。真实缺边、自交或退化导致无法唯一计算时提示整理边界；不会将人工点选当作补线推定。内孔按有效围合关系扣除。计算层和标注层关闭、冻结或锁定时提示处理，不自动解锁。

## 标注、植物和统计

标注点自动避开内孔和凹形区域之外，字高在原出图设置基础上适应区域宽度。可用CAD移动、属性编辑调整文字位置和字高。补标入口为“标注 → 区域编号或植物名称与面积”，选计算边界后指定位置。

需要植物分类汇总时，支持两种关联方式：

1. 新标注：在“项目规格”选好灌木，点击“设为当前规格”；用“编辑 → 已算面积关联当前植物”，选择对应区域的面积文字或计算边界，可多选，回车确认。
2. 已有品种标注：用“编辑 → 从已有品种标注关联面积”，先点已有名称/品种标注，再选择对应面积文字或计算边界，回车确认。CountingTrees（数树）标注直接取得原规格；普通TEXT、MTEXT、MLEADER、属性及可分解图块文字匹配项目中完整名称或编号。安装的天正等扩展若能提供普通文字分解结果也可读取；不在图纸中实际分解原标注。

同名多个规格时，优先用明确的规格编号；只提供名称、无法唯一匹配或专用标注不支持读取时，提示到“项目规格”明确选定，再用第一种方式关联，不沿用不相关的当前植物。

关联后面积标注变成“灌木名称＋xx平方米”，保留约数和补线推定提示，统计按品种/规格汇总；选择面积文字与同一边界不会重复关联。原品种标注保留，面积数值和几何保持。未关联时按区域编号单列。用统计菜单查看、生成数量表或导出CSV，面积单位为平方米。

## 单位、植物规格和保存

植物规格以cm输入，底图模型仍可采用mm、cm或m。INSUNITS仅作提示；真实比例不明时用“设置 → 按已知长度校准单位”，点两点并输入真实cm长度。各已生成对象保留自己的单位记录，不缩放底图。

植物规格竖排为冠幅、高度、胸径、地径。胸径/地径可只填一个，未填为——；草类可无规格。新规格带可修改的设计初值，同种植物优先沿用上次确认尺寸。项目支持分类及名称/编号检索，图中单株可双击编辑，改真实尺寸用独立编号。

单株图例和外置名称标注在未填写所选胸径或地径时，不再显示下方横杠。有实际径值时照常显示。已有单株执行“更新关联标注”刷新；规格输入框和表格的缺值表示仍保留。

项目植物、待选清单、尺寸记忆、单位及面积记录随当前DWG保存。退出前Ctrl+S，或“设置 → 保存项目到当前DWG”。保存位置可在设置菜单查看。

不绑定键盘组合，不改天正/CAD的CUI或PGP；只读面板刷新不进入撤销记录，绘图操作保留撤销。手动绘图不需要AI连接。
