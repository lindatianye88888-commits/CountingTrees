# 0.3.23 保留说明

本目录保留兼容性修改前的 AutoCAD 2014 x64／天正 TArch9 版本。

运行文件、DLL、安装器、C# 源码、构建脚本和三份主要说明取自本地 0.3.23 回滚快照；其余配套文件以原 0.3.22 完整包为底本补齐，并恢复 0.3.23 数树命名。LISP 运行文件全部逐项匹配原 0.3.23 manifest.json 的 SHA-256，对应 UTF-8 源文件已验证可转换为相同运行文件。这是根据现存快照整理的可安装保留包，并非声称找到了原始未修改的 0.3.23 完整发布包。

解压安装包后，运行安装操作面板.cmd。安装会替换本机现有数树插件；安装前保存图纸并关闭 CAD。实机验收范围以原 manifest.json 和文档为准。
