# PlantCAD整体复查报告

版本：0.3.21。日期：2026-10-21。状态：代码复查、自动规则、原生内核和独立控件检查完成；完整CAD桌面交互验收待完成。

## 复查范围

检查主要命令入口和数据通路，覆盖植物库/项目规格/单株与灌木球、单位与比例、曲线求交/闭合/内孔/推定补线、区域标注与整体引线、填充、全图总表及分类/品种分表、直接改名反馈、窗口筛选/缩放、本地结构化连接、安装和打包。保留普通CAD删除/撤销之后不自动整图写入的约束。

## 已复现并修复的问题

| 问题 | 复现证据 | 修改后的行为 |
| --- | --- | --- |
| 圆弧闭环随选择顺序漏算 | 同一案例旧版内核117、桌面115；打乱输入后内核114 | 固定计算顺序；解析处理直线/圆弧交点；对CAD拒绝的少量接缝做有面积误差上限的局部拟合，保留主要圆弧 |
| 复合面域填充失败 | 两个分离矩形组成面域，旧代码返回eInvalidInput | 递归收集完整边界；分离外环各自标为外环，内孔保留；替换失败保留旧填充 |
| 重扫和升级产生平行记录 | 初次登记119条区域、再次120；有两条实际相同的拟合边界 | 包围盒只作初筛，实际通过局部交集或完整边界比对；极短边优先比完整参数。现初次和重扫均118条区域 |
| 菜单声称可看范围，实际仅识别单株 | 原info-work只调用plant | 边界、面积文字、引线和填充均可追溯区域，显示面积、植物、推定补线及拟合来源 |

拟合仅处理接缝邻域；最多2048段、7次尝试。每次建立原生面域后都与原圆弧面积积分核对，面积差须在max(数值容差×周长×4,数值容差²)内。原始边线不被拟合替换。没有采用密集整弧细分兜底。

## 案例覆盖与数值回归

- 原117个已核对区域逐个对比包围盒和面积，全部保留；最大数值差异约0.000002649平方米。这是模型结果回归对比，不是现场测量精度承诺。
- 原序、反序、编号序、打乱顺序均为118个几何闭合图形，轮廓和面积一致。额外一个是极小边角；另一个不可靠碎片提示核对。
- 118个含停车格等非种植图形，不等于118块灌木。关联植物前仍需设计师判断用途。
- 全部输出区域有内部面积文字；8个原漏算位置有对应区域。旧区域复用、拟合来源保存及重扫不增加区域/文字检查通过。
