## 本机构建

在项目根目录执行：

```powershell
python -X utf8 -B PlantCAD-0.3/developer/build.py
python -X utf8 -B PlantCAD-0.3/developer/render_workbench.py
python -X utf8 -B PlantCAD-0.3/developer/verify_release.py
```

需要 Windows .NET Framework 4 编译器、本机合法安装的 AutoCAD 2014 x64 SDK DLL 以及 Python 3。CAD SDK DLL 不放入分发包。构建脚本可通过 PLANTCAD_CAD_DIR 或 --cad-dir 指定实际 CAD 目录。

安装器默认要求全部 CAD 退出；`python PlantCAD-0.3/install_panel.py` 与双击安装 cmd 相同。更新运行包后再安装，确保 DLL 和 LISP 配套。

## 数据与AI入口

单株保留 TREE 标记及规格快照；种植范围使用 AREA 标记，另存 AREA_PLANT 和 UNITS。面积单位只在统计行派生，不覆盖项目规格的单株/丛单位。范围标注使用 AREA_LABEL 关联范围实体。

统计按名称、类别、真实规格、规格编号和计量单位分组。苗木数量表保存统计范围，AI刷新时使用同一范围；范围面积来自当前几何，不能用旧快照面积覆盖。

Codex入口为 bridge/mcp_server.py。安装包中的 queue-root.json 指向当前目录 bridge/runtime，保持已配置连接可用。手动菜单不依赖 MCP；点击“设置→连接当前图纸到AI”才绑定 AI 图纸。WorkBuddy 和 DeepSeek 的客户端模板在 bridge/clients。

不扩大 AI 工具允许的动作，不执行来自客户端的任意脚本，不自动保存图纸。

## 本轮尺寸与启动实现

植物高度/冠幅仍按原协议以米保存，胸径/地径仍以cm保存；UI输入和显示通过dimension-input/dimension-cm转换。显式_m的MCP字段保留兼容性，表格和人读规格均为cm，不对已存在的DWG快照做数值重写。

品种tags为可选第8列，兼容7列导入。常绿/落叶来自形态分类，彩叶/开花由设计师勾选。右侧选择集合按ID合并，保留筛选外选项。

原生扩展初始化只安排小圆标，等待CAD真正Idle后显示；双击展开再按图纸准备绘图模块。Core Console直接跳过桌面控件初始化。标题栏双击由WM_NCLBUTTONDBLCLK处理，内容标题/预览使用DoubleClick事件。圆标为同一源码中的WinForms控件。

安装清单在ComponentEntry上启用LoadOnStartup（2014兼容）和LoadOnAutoCADStartup，保留命令入口，不修改APPAUTOLOAD或可信路径。格式依据[Autodesk组件启动参数](https://help.autodesk.com/cloudhelp/2018/ENU/AutoCAD-Customization/files/GUID-3C25E517-8660-4BB7-9447-2310462EF06F.htm)及[Autodesk 2014部署示例](https://static.au-uw2-prd.autodesk.com/handout_4888_SD4888-L-Getting_20Started_20with_20C3D_20.Net_20Programming.pdf)。

developer/verify_startup_badge.py仅在没有CAD运行时启动自建input.dwg副本。启动过程的临时窗口可能销毁，应跳过失效句柄；若宿主初始化未完成，报告未通过并结束自己的测试，不附加到用户图纸。

旧版受管理数量表或规格表刷新时，表头单位和数据同时更新为cm，避免旧m表头配上cm数值。

## 曲线面积、规格与撤销

PlantAreaGeometry.cs 对脱离数据库的曲线副本建立交点和有向边拓扑，遍历有界面；Region.CreateFromCurves提供曲线原生面积。不同图层对象不进入计算，原图层状态不变；归零和颜色统一由前置事务修改框选原线，其后拓扑修复不再改写原线。采样仅用于方向和点归属，面积不使用折线近似。预处理后图元须水平共面，数值容差仅处理坐标误差；可推定缺口由独立修复步骤连接并标记。计算面域是快照。

AutoLISP完成ssget/entsel交互；PlantAreaInteraction.cs仅消费显式句柄、识别黄色图层、去重、写入面域及读取面积。原生逐点接口保留兼容，主流程自动全部标注。pl:range-work在结束或取消时释放会话，AREA同时支持旧LWPOLYLINE与新REGION。

尺寸修改由prepare-edited-spec分配新ID和编号，保留旧定义；图中单株编辑再按physical-key复用相同规格并更新原句柄。PlantInstanceEditing.cs只针对PlantCAD TREE双击，否决该对象的标准属性编辑后在CAD空闲时调度独立规格编辑，不修改CUI或普通图块的行为。天正真实鼠标双击仍待验收。

UNIT=3使用UNITS_PER_M校准值。旧0/1/2单位索引与对象UNITS保持兼容。新增SIZE_DEFAULTS和CATALOG_PICKED随DWG保存，未改原MCP单位协议。

不注册全局组合键；默认不启用PL短别名，原生桥接命令也统一PLANTCAD前缀。只读浮窗命令含NoUndoMarker/NoHistory，避免面板刷新进入撤销队列。

原生复现：verify_area_native.py、verify_workflow_native.py均须提供--drawing测试DWG。前者检查精确曲线围合；后者使用无界面宿主适配层验证面积登记和DWG保存重开，不能替代桌面COM与鼠标验收。相关范围在报告中明确记录。

## 先几何后植物（0.3.10）

## 自动恢复与全部标注（0.3.10）

PlantAreaRepair.cs是PlantAreaGeometry的partial实现。先做真实交点拆分，再从度数为1的线头推导候选连接：局部距离/切向延长、简单线串闭合、平行窄带封端；分轮重建拓扑，不修改输入实体。闭合面由CAD Region生成，补线依赖跟随面域及孔洞传播到Repaired标记。内孔要求完整嵌套，不以单个共享点判定。

InteriorPoint使用有界优先搜索和边界距离选点，排除孔洞，为凹形和窄带提供内部标注锚点。native-area-export-all一次返回AREA_BATCH及(handle, point, repaired, radius)行；LISP不再调用getpoint逐块登记，而是遍历所有行写入AREA_NO/UNITS/AREA_REPAIRED并生成MTEXT。0.3.15起重新扫描返回已有区域供内部文字复查，保留编号及植物关联；同次会话的重复导出仍跳过。推定连接另写AREA_REPAIR辅助线，原始边界不变。

这是带推定恢复的CAD几何算法；未知缺边不能产生唯一真值。约数标记、红色辅助线及未解轮廓提示是结果的一部分。AutoCAD2014内核用例和无界面适配流程分别记录，不当作天正GUI验收。

### 数值闭合与面域容差（0.3.20）

原图节点合并成功并不表示ACIS接受各曲线端点。先保留原曲线尝试建立面域；失败时，仅对LINE/ARC且邻接连续的闭环建立共享节点、带圆弧凸度的闭合Polyline。所有端点移动受原joining tolerance约束，圆弧方向和曲率信息保留；原始Entity不改。按原圆弧面积积分校验面域面积差，超出tolerance×周长×4的结果拒绝，不能通过扩大缺口容差强行合并相邻区域。


世界坐标恢复后的面域面积会受大坐标浮点消减影响。按坐标绝对值×机器精度×图形跨度×8估计误差界，同时考虑端点容差×周长×4。低于该界的极窄碎片不作为可靠种植面积，单独计数提示。该阈值随坐标及图纸单位缩放，不按显示两位小数截断正常小区域。

既有面域判重在共同局部坐标内完成，使用同一局部面积作交集比较。仅当包围盒与面积都在数值误差界内时尝试复用；布尔运算失败后，对LINE/ARC/CIRCLE组成的完整边界作双向多点距离校核。复合面域分解后若仍为Region，继续递归收集曲线，并限制递归深度和曲线数量。未匹配的旧实体保留，不能让一个旧面域的建模异常阻断本次新区域输出。


### 整体复查补充（0.3.21）

PlantAreaGeometry在克隆前按几何键固定顺序和局部原点；直线/圆弧使用解析求交，近切判定限定原joining tolerance。原曲线和共节点圆弧面域都失败后，FitRingJoints仅修整接缝邻域，主要段保留bulge；最多2048段、7次尝试。每次原生Region面积都与原圆弧积分比较，必须在max(tolerance×周长×4,tolerance²)内。没有整弧密集分段兜底。

世界坐标误差界按各Face位置、范围和参与圆弧半径估计；远处尾线不会直接扩大每块小面积的误差。AREA_FITTED单独保存，不混同AREA_REPAIRED推定补线。范围属性可查看来源。

面域判重的包围盒只作宽阶段排除；实际复用仍需局部交集面积或完整双向边界校核。极短边先用完整Line/Arc/Circle参数一对一比较，绕开相同ACIS边也可能失败的最近点查询；不删除未匹配旧实体。

OutputLoops通过有深度和数量上限的CollectAreaBoundary提取复合面域的完整曲线。OutputOuterLoops在局部坐标判定包含关系，分离外环均标Outermost，内孔标Default；任何失败回滚填充替换事务。依据[Autodesk填充边界说明](https://help.autodesk.com/cloudhelp/2017/ENU/AutoCAD-NET/files/GUID-01A47A4F-9FC5-4DB6-8C3E-B72D75688965.htm)，并由AutoCAD2014原生复合面域测试验证。

开发验证新增case2-baseline.json保存原117个已核对区域的包围盒与面积，verify_case_order.py独立逐个比对并打乱选择顺序。最终GUI记录不足时保留发布门禁，不把内核和WinForms控件检查混称为CAD完整桌面验收。
